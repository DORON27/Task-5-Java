# Bank Account Simulation (Java OOP)
---
## Overview
This project is a simple **Bank Account Simulation** built in Java using Object-Oriented Programming (OOP) concepts.  
It demonstrates how to model real-world banking operations like deposits, withdrawals, and transaction history.
---
## Objectives
- Practice OOP fundamentals in Java.
- Implement a class-based program with methods and attributes.
- Simulate real-world scenarios such as account management and transactions.
---
## Features
- `Account` class with:
  - Account holder name
  - Balance tracking
  - Transaction history
- Methods:
  - `deposit(double amount)`
  - `withdraw(double amount)`
  - `printTransactions()`
- Handles failed withdrawals gracefully (e.g., insufficient funds).
